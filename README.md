# ForgePad

A privacy-first local text and developer workbench.

## Features

- Markdown editor with live preview
- JSON formatter and minifier
- Text diff
- Regex tester
- Base64 and URL encode/decode
- Text statistics and case transformations
- Local snippets with import/export
- Autosave and keyboard shortcuts
- Responsive desktop/mobile UI
- Optional Python local server

## Run

```bash
python server.py
```

Then open `http://localhost:8000`.

ForgePad is designed to run locally. Your working text and snippets stay in the browser unless you explicitly export or send them elsewhere.
